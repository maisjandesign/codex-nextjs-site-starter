# Screenshot → Next.js

1. Inspect the image at its actual resolution. Record section order, visual hierarchy, estimated container width/columns, typography, spacing, image crops and visible states. Distinguish observed facts from estimates. A screenshot does not specify hover, mobile layouts or exact font metrics.
2. Build a map of image slots: subject, aspect ratio, palette, lighting, camera angle, background, focal point and surrounding negative space. Existing user-provided original assets win. For missing photos/complex illustrations, use built-in image generation guided by the screenshot, one asset per meaningful slot. Generate the image asset, not the full webpage or its UI text.
3. Inspect each generated candidate and match its composition/crop in the actual slot. Copy chosen output into `public/assets/generated/`; save its final prompt, source reference and status in `design/assets.json`. Mark generated images as approximations. Do not substitute decorative gradients for photographic content.
4. Recreate UI, typography, borders and simple geometry in HTML/CSS. Prefer source SVGs for logos/icons when available. For unknown brand marks, ask for the asset if exact reproduction matters; do not silently invent a brand. Use one coherent icon family for generic UI where no source asset exists.
5. Cluster similar measurements into shared tokens. Use round-to-nearest-8 integer dimensions; typography has one global role per heading level and breakpoint. No one-off fine-tuning with fractional pixels. Preserve the reference's character while noting normalization.
6. Use the original screenshot width for the first comparison. Check layout silhouette, typography/line endings, image subject/crop, spacing and small details in that order. Compare finished static animation states. Then test responsive layouts and interactions inferred from the UI.
7. Unavailable image generation is a real capability limit. Report it and continue the layout/typography work; do not claim final visual fidelity with missing assets. Do not call a generation CLI or billed API without authorization.
